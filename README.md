# Venta de Autos Flutter 

## Descripción

Aplicación móvil desarrollada con Flutter y Dart para consultar, publicar y administrar vehículos en venta.

Este proyecto se realiza como trabajo final de la materia de Desarrollo de Aplicaciones Móviles.

## Objetivo

Desarrollar una aplicación funcional que permita a los usuarios visualizar información de automóviles, publicar vehículos y administrar sus anuncios.

## Tecnologías

- Flutter y Dart
- Firebase Authentication
- Cloud Firestore
- Almacenamiento de imágenes en la nube
- Git y GitHub

## Funcionalidades planificadas

- Pantalla de bienvenida
- Catálogo de vehículos
- Detalles de cada automóvil
- Registro e inicio de sesión
- Publicación de vehículos
- Edición y eliminación de anuncios
- Almacenamiento de información en Firebase
- Subida de fotografías a la nube
